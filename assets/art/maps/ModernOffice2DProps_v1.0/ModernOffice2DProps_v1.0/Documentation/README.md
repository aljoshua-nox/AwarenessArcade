# Modern Office 2D Props Pack

Version: v1.0

## Contents

- 54 individual transparent PNG assets
- Furniture, electronics, desktop props, and office decor categories
- Regular-grid PNG tilesheet with JSON metadata
- Packed PNG texture atlas with JSON frame and anchor metadata
- Preview generated from the included individual Tiles

## Format

- Image format: RGBA PNG
- View: top-down three-quarter
- Style: 2D flat cartoon
- Default anchor: bottom-center contact area
- Background: transparent

## Import

Use `Tiles/` when importing individual sprites.

Use `TileMap/modern_office_tilesheet.png` with its matching JSON for a
fixed-cell atlas. Use `modern_office_tilesheet_packed.png` with its matching
JSON when a compact texture atlas is preferred.

## Not Included

- Characters or animation
- Walls, floors, doors, windows, or other architecture modules
- Engine-specific Unity or Godot project files
- Source generation sheets or prompts
- A reproducible sample office scene

## AI Disclosure

The artwork was created with AI-assisted generation and then processed into
separate transparent game assets.
